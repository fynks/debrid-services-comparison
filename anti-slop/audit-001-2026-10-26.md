# Anti-slop audit 001 — debridcompare.pages.dev

Date: 2026-10-26 · Mode: AFTER · Scope: `index.html`, `src/**` (site UI only; README files out of scope)
Rule tiers: Hard Gate = HIGH · Purpose-Gate = MEDIUM · Quality Locks = LOW

## Findings

1. **[HIGH · R-38, R-36]** `index.html` ships a `FAQPage` JSON-LD block with 8 questions/answers, but the page has **no FAQ section** — the UI never renders it. Ghost structured data describing content that is not present. Evidence: JSON-LD at `index.html:186-248`; no `#faq` section/anchor exists.

2. **[HIGH · R-36, R-17]** Same JSON-LD block claims `"Compare 10 premium debrid services"` (`index.html:111`). The site compares **9** (`src/json/file-hosts-optimized.json` has 9 services). Inaccurate count in structured data.

3. **[HIGH · R-36]** Every provider card in "Live service status" shows an unconditional green **"Live"** badge (`status-grid.js` `statusCard()`). No live status data is fetched anywhere; the badge asserts verified uptime the page does not have.

4. **[HIGH · R-25]** "Not supported" cells render `-` at `text-muted-foreground/30` → measured **1.48:1** (light) / **1.82:1** (dark). The ✕ marks for unsupported render at `/40` → **1.70:1** / **2.34:1**. All are below WCAG AA (3:1 even for large glyphs). Screen readers are covered by `aria-label`s, but the visual marks carry meaning and are near-invisible to low-vision users.

5. **[MEDIUM · R-14]** "Key benefits" grid (`index.html:428-457`) is four identical cards — same size, icon chip, padding, layout; no hierarchy between "Multi-host access" (core) and the rest.

6. **[MEDIUM · R-09, R-31]** Eyebrow labels sit above every section headline and mostly restate it (`Usenet` → "Usenet support", `Speed test` → "Speed test & performance", `Status` → "Live service status", `Disclaimers` → "Important information"). No pill/border/dot (so not the full R-09 capsule), but the label adds no information the h2 lacks.

7. **[LOW · R-05]** Uniform section rhythm: all 11 sections use the same internal composition (centered eyebrow + h2 + subtext → content → info/warning callout); alternating `bg-muted/30` is the only variation. Content differs per section; the template does not.

8. **[LOW · R-05]** Footer is the generic 4-column template shape (brand + Compare/Resources/Community columns). All links point to real sections (no R-24 violation).

9. **[LOW · R-16]** `src/data/resources.ts:14` — "…debrid add-on ecosystem for **seamless** streaming" (AI-marketing buzzword).

10. **[LOW · R-36]** Superlative without source: Comet is "Stremio's **fastest** torrent/debrid add-on" with tag `"Fastest"` (`resources.ts:112-113`).

11. **[LOW · R-17, R-38]** Search placeholder says `Search 322+ hosts` (`host-support-table.js:42`) — the count is exactly 322; the `+` overstates it.

12. **[LOW · R-06]** Table headers (`th()`, `headerCell()`, resource-group summaries) use `uppercase tracking-wider` — the AI-default label styling. The section-header override in `globals.css:245-251` neutralizes letter-spacing for the eyebrow only (via unlayered rule beating utilities), so table headers keep wide tracking; inconsistent for no stated reason.

13. **[LOW · R-32-adjacent]** Mobile drawer (`mobile-nav.js`) opens/closes via the toggle button and closes on link click, but has no Escape handling and no `aria-controls` wiring from the toggle. Non-modal disclosure, so severity is low.

14. **[INFO · hygiene]** Stale comments: "328-row table" (`host-support-table.js:413`), and dead code — `main.js:41` queries `[data-mount="hosts-count"]` which no longer exists in `index.html`. Comments skill (antislop-code) not installed yet; listed for its next session.

15. **[INFO · R-37]** No `DESIGN.md`. The existing design system (tokens, single radius scale, type scale, semantic colors) is already documented inline in `globals.css` with written reasons — fixes can proceed under that existing direction without inventing one.
